Conclusión

En esta parte vimos cómo funcionan algunas etiquetas, explicado de forma sencilla:

  • <h1> ... <h6> son los títulos. El número indica qué tan grande o importante es el título.
  • <img> sirve para poner una foto en la página. Se le puede decir qué ancho debe tener y qué texto mostrar si no carga.
  • <video> se usa para ver un video dentro de la página. Le puedes pedir que empiece solo o que vaya sin sonido.
  • <table> es como una hoja de cálculo: filas y columnas para organizar datos (productos, precios, etc.).
  • <textarea> es una caja donde se puede escribir mucho texto, como comentarios o respuestas largas.

Todos estos elementos son partes de una página web. El navegador los muestra como están y cambia según lo que le pidamos con atributos como width, placeholder, etc.
